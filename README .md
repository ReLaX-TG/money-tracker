# Money Tracker

Money Tracker is a simple web application for tracking personal income and expenses, created with the help of AI.

## Features

- Add income and expenses.
- Automatic balance calculation.
- Expense categories: Groceries, Transport, Housing, Health, Entertainment, Other.
- Expense analytics by category, including a chart and percentage breakdown.
- Transaction history with the option to delete entries.
- Data storage in the browser using `localStorage`.
- English-language interface and support for the PLN (zł) currency.

## Technologies

HTML, CSS, JavaScript, `localStorage`.

## How to Run

1. Download the `index.html` file.
2. Open it in your web browser.
3. Start adding your income and expenses.

No server or additional software installation is required to run the application.
